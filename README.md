# 💰 Personal Finance Management API

Shaxsiy moliya va xarajatlarni boshqarishga mo'ljallangan RESTful API loyihasi. Ushbu loyiha Django va Django REST Framework (DRF) yordamida ishlab chiqilgan.

## 🚀 Texnologiyalar va Kutubxonalar
- **Python** (v3.14)
- **Django** (v6.1.2)
- **Django REST Framework (DRF)**
- **drf-spectacular** (Swagger va Redoc API hujjatlari uchun)
- **SQLite** (Ma'lumotlar bazasi)

---

## 📌 Asosiy Imkoniyatlar
- 👤 **Account (Hisoblar):** Foydalanuvchi hisoblarini boshqarish va balansni kuzatish.
- 📈 **Incomes (Kirimlar):** Kirim tranzaksiyalarini qo'shish va boshqarish.
- 📉 **Chiqimlar (Expenses):** Chiqim va xarajatlarni qayd etish.
- 📊 **Dashboard:** Umumiy moliyaviy holat va balansni hisoblab beruvchi maxsus oynasi.
- 📂 **Media:** Fayllar va rasmlarni yuklash hamda saqlash imkoniyati.

---

## 📖 API Hujjatlari (Swagger & Redoc)
- **Swagger UI:** [http://127.0.0.1:8000/swagger/](http://127.0.0.1:8000/swagger/)
- **Redoc UI:** [http://127.0.0.1:8000/redoc/](http://127.0.0.1:8000/redoc/)
